## 💻 অফিশিয়াল কমপ্যানিয়ন কোডবেস (Companion Repository)

বইটিতে আলোচিত সমস্ত এক্সিকিউটেবল পাইথন কোড, মক ডেটাসেট এবং সিআই/সিডি অটোমেশন আলাদাভাবে সাজানো রয়েছে কমপ্যানিয়ন রিপোজিটরিতে:

👉 **[github.com/raqueeb/fdebook_companion](https://github.com/raqueeb/fdebook_companion)**

* **জিরো-ক্লাউড আর্কিটেকচার:** কোনো পেইড ক্লাউড সাবস্ক্রিপশন ছাড়াই ১০০% অন-প্রেম লোকাল রানটাইম।
* **স্ট্যান্ডার্ড লাইব্রেরি ফার্স্ট:** সাধারণ Python 3.10+ দিয়েই ৩ সেকেন্ডে রানযোগ্য।
* **লোকাল এআই ও ট্রায়াজ:** Ollama ও Qwen 2.5 দিয়ে কাস্টমার টিকিট ট্রায়াজ এবং গোল্ডেন টেস্টবেঞ্চ।
* **সেলফ-হিলিং সিআই/সিডি:** ভাঙা ডেপ্লয়মেন্ট হলে তাৎক্ষণিক লাস্ট-স্টেবল অটো-রোলব্যাক।

## 🛠️ লোকাল প্রিভিউ ও বিল্ড নির্দেশিকা

বইটির ডকুমেন্টেশন সাইট লোকাল মেশিনে বিল্ড বা প্রিভিউ করতে:

```bash
# ১. রিপোজিটরি ক্লোন করুন
git clone https://github.com/aiwithr/fde_book.git
cd fde_book

# ২. MkDocs ও Material থিম ইনস্টল করুন
pip install mkdocs-material

# ৩. লোকাল ডেভেলপমেন্ট সার্ভার চালু করুন
python -m mkdocs serve
# ব্রাউজারে দেখুন: http://localhost:8000/
```

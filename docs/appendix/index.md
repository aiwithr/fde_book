# অ্যাপেন্ডিক্স ও ফিল্ড রেফারেন্স

> **বিষয়বস্তু:** চেকলিস্ট, ল্যাব সেটআপ গাইড ও পরিভাষা  
> **স্ট্যাটাস:** রেফারেন্স সেকশন

## ১. ফিল্ড ডিসকভারি অডিট চেকলিস্ট

ক্লায়েন্টের সাইটে প্রথমবার অন-বোর্ডিংয়ের সময় একজন ফরওয়ার্ড ডেপ্লয়েড ইঞ্জিনিয়ারের সাথে যা যা রাখা জরুরি:

* [ ] ক্লায়েন্টের বর্তমান আইটি ও সার্ভার হার্ডওয়্যার স্পেসিফিকেশন তালিকা
* [ ] ইন্টারনেট কানেক্টিভিটি ব্যান্ডউইথ ও লোকাল নেটওয়ার্ক আইসোলেশন প্যারামিটার
* [ ] ক্লায়েন্টের বিদ্যমান এসওপি ডকুমেন্ট (শ্যাডো সেশনে এর ফাঁকফোকর খোঁজার জন্য)
* [ ] ডেটা প্রাইভেসি এবং সিকিউরিটি কমপ্লায়েন্স প্রয়োজনীয়তা
* [ ] প্রধান স্টেকহোল্ডার এবং ডোমেইন বিশেষজ্ঞদের যোগাযোগের তথ্য
* [ ] অফলাইন পোর্টেবল টেস্ট এনভায়রনমেন্ট (Ollama, কিউয়েন মডেল ও টেস্ট ডেটা সহ ল্যাপটপ)

---

## ২. গিটহাব ল্যাব টেস্ট-ড্রাইভ ও সেটআপ গাইড

বইয়ের প্রতিটা কোড নিজের মেশিনে টেস্ট করার জন্য অফিশিয়াল গিটহাব রিপোজিটরি ক্লোন করুন:

```bash
git clone https://github.com/aiwithr/fde_book.git
cd fde_book
```

লোকাল মডেল অর্কেস্ট্রেশনের জন্য প্রয়োজনীয় টুলস:
* Python 3.10+
* Ollama (https://ollama.com)
* Qwen 2.5:1.5b মডেল (`ollama run qwen2.5:1.5b`)

## ৩. পেজ বাজেট ও ওয়ার্ড কাউন্ট সামারি

| বইয়ের ইন্ট্রোডাকশন ও ব্যাকগ্রাউন্ড | ১৫ পেজ | ৪,০০০ ওয়ার্ড |
